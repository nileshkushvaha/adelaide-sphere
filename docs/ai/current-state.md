## Security posture (implemented)
Argon2id passwords; opaque sessions (`as_admin_session`, HttpOnly, SameSite=Strict, Path=/api/v1/admin, 30 min idle/12 h absolute); CSRF Origin guard; login/reset throttling (fail-safe 503); default-deny permissions guard; audit log; AES-256-GCM field encryption (`FIELD_ENCRYPTION_KEY`) for TOTP secrets and private enquiry emails; helmet strict CSP on the API; 64 KB body cap; env validation refuses insecure production values. Privileged admin mutations are metered (20/min, 200/h per administrator; per-process fallback during a Redis outage; `429` + `Retry-After`). Production refuses to start without verified MySQL TLS (`?sslmode=verify-ca|verify-identity`) or with `DATABASE_ALLOW_PUBLIC_KEY_RETRIEVAL=true`. Not yet: Turnstile/public form limits (16), retention jobs, web-tier TLS/CSP/headers (23–24).

## Staging closure (2026-09-09)
- **Metrics are reachable the way a deployment reaches them.** API `/metrics` and the worker's `/metrics` answer only a loopback caller or `Authorization: Bearer <METRICS_TOKEN>`; everything else gets 404. Proven with Prometheus **in its own container** scraping three targets (api + two worker replicas) through a mounted token file. Through the public edge, `/metrics` returns the site's not-found page — it is not routed publicly.
- **`WORKER_METRICS_BIND`** (default `127.0.0.1`) must not be widened without a token; the configuration refuses it.
- **F-05 (empty 404 body) is fixed at the reverse proxy**: `infrastructure/edge/nginx.conf` + `infrastructure/edge/docker-compose.edge.yml` (profile `edge`, pinned `nginx:1.29.4-alpine`, port published on loopback only). D5–D9 used a TCP forwarder, an isolated `adelaide_sphere_drill` database and Redis database 9, so no shared container was stopped.
